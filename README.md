# 滨江线条实验室

盘扣微课第二课的互动学习网站。围绕“找主线、去细节、留特征”，从杨浦滨江建筑照片出发，完成观察、线稿比较、手绘概括与城市生活说明。

[打开当前在线版本](https://binjiang-lineart-lab-20261111.zhangwencaa1988.chatgpt.site)

## 学习功能

- 选择十处课程地标，或上传自己的 JPG、PNG、WEBP 照片。
- 在浏览器内提取边缘线条，调整阈值、平滑程度和线宽。
- 每次只改变一个参数，切换 A、B 版本进行有依据的比较。
- 在淡底稿上画出自己的概括线条，使用橡皮、撤销和原照片对照。
- 通过取舍挑战获得具体反馈，记录留下、删去的内容及城市生活联系。
- 导出线稿、手绘概括 PNG，以及包含原照片、底稿、概括稿、参数和说明的作品记录。

图片只在当前浏览器内处理，不会上传。刷新页面会清空未导出的图片与笔迹，请及时保存。工具使用本地边缘检测，不运行 ControlNet 或云端 AI，也不会替学习者识别地标或作设计取舍。

## 用 GitHub Pages 发布

本仓库根目录就是完整网站，无需安装依赖或运行构建。

1. 将全部文件保留在 `main` 分支的仓库根目录，包括 `assets/` 文件夹。
2. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)`，保存。
4. 等待发布完成，使用 Pages 页面显示的网址分享给学生。

资源使用相对路径，支持 GitHub Pages 项目网址。请通过 HTTPS 网站或本地 HTTP 服务打开，不要直接双击 HTML 文件。
