# 建筑图形概括工坊

盘扣微课第二课的单屏互动工作台。围绕“观察建筑、提线实验、动手概括”，从杨浦滨江地标或自己的照片出发，选择轮廓与主要结构，完成简洁而有特点的建筑图形。

## 功能

- 10处课程地标选择、资料介绍与本地图片上传。怡和1915为插画参考。
- 在原照片中框选主体，并可恢复全图。
- 独立调节Canny风格边缘检测的低阈值、高阈值和平滑。
- 三档预设是阈值方案比较；单项实验应只移动一个滑块。阈值不是重要程度评分。
- A/B按钮比较未经手工处理的原始提线结果。点击画笔、橡皮或模式按钮，可恢复各版本保存的人工取舍。
- 清理底稿时可直接擦去自动提取的线，也可补画主线，支持撤销。
- 手绘概括模式以淡底稿辅助观察，导出时只保留自己的笔迹。
- 三道有解释的判断挑战；导出清理稿、手绘概括PNG及图文观察记录。

主界面按视口高度布局，无需上下滚动。桌面和平板使用左右双栏；手机通过上方“素材与实验／我的概括画板”切换，仍留在同一页面。玩法、地标资料和保存表单通过弹窗打开。

## 技术与隐私

纯静态HTML、CSS、JavaScript与浏览器Canvas；无需登录、API密钥、云端推理或数据库。图片在当前浏览器内处理，不上传。刷新会失去未导出的工作，请及时保存。

本工坊没有运行ControlNet，也不会自动判断建筑的语义主次。ControlNet可在其他支持它的生成工具中接收整理好的条件稿，继续尝试材质和风格。盘扣风格图不等于已经验证扣合功能的实物。

双阈值范围0—255只是本工具的参数范围，不是Sobel梯度强度的通用上限。Canny实现使用透明白底、二项平滑、Sobel L2梯度、非极大值抑制与8邻域滞后连接。与OpenCV不承诺逐像素相同。

## 素材

背景为用户提供的滨江水彩图，网页使用无缩放JPEG压缩版本；10处地标素材由课程提供，来源说明保留在界面资料与导出记录中。
